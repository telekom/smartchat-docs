# Artifacts

Source: https://docs.smartchat.ai.t-systems.net/user/agents/artifacts/

> Find, open, download, continue editing and delete the files that agents produce.

> **Preview**
>
> Agent Mode and its artifacts are currently in preview only. If you would like to test these features, please contact your T-Systems representative.

**Artifacts** are the files an agent produces in [Agent Mode](https://docs.smartchat.ai.t-systems.net/user/agents/), such as spreadsheets, presentations or documents. They are kept per Space, so you find them again after the chat.

## [In the chat](https://docs.smartchat.ai.t-systems.net/user/agents/artifacts/#in-the-chat)

Every file an agent created in this chat.

- Each file the agent delivers appears as a card under its answer, with **Open** and **Download**. A card marks a file that was deleted since.
- **Artifacts** in the chat header, with the number of files, opens a panel with all of the chat’s artifacts, including those from earlier sessions.

## [The Artifacts page](https://docs.smartchat.ai.t-systems.net/user/agents/artifacts/#the-artifacts-page)

**Artifacts** in the sidebar, below the Workspace, lists all artifacts of the active Space. Search by name, sort by any column, and click an artifact to open its page: its type and details, **Download**, and a link back to the chat that produced it.

Artifacts without a chat stay here too.

## [Continuing to edit an artifact](https://docs.smartchat.ai.t-systems.net/user/agents/artifacts/#continuing-to-edit-an-artifact)

1. Choose **Continue editing** in an artifact’s row menu, or click the **Continue editing** button on the artifact’s page.

   Continue editing opens the chat the artifact came from.

2. Smartchat opens the chat the artifact came from, or a new chat if it has none. The artifact is shown above the message box.

3. Describe your changes and send the message. An agent with a sandbox updates the file instead of making a second one.

## [Deleting artifacts](https://docs.smartchat.ai.t-systems.net/user/agents/artifacts/#deleting-artifacts)

- **Delete** in an artifact’s row menu or on its page deletes it after a confirmation.
- When you delete a chat that has artifacts, the confirmation lists them and offers **Also delete its artifacts**. It is unchecked, so the artifacts stay on the Artifacts page unless you tick it.

The option is unticked: without it, the artifacts stay.
