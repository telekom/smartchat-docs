# Glossary

Source: https://docs.smartchat.ai.t-systems.net/user/glossary/

> Glossary of key terms used in Smartchat.

| Term | Meaning |
| - | - |
| **Application Owner** | Global responsibility for the entire Smartchat application; can manage all spaces and users. |
| **API Key** | A unique access key that allows external systems to securely access Smartchat functionality. |
| **Workspace** | An area for creating, editing, or deleting custom resources (assistants, knowledge collections, prompt templates). |
| **Workspace Resources** | Three categories: assistants, custom knowledge, and custom prompt templates, each individually created/customized. |
| **Auto-Sync** | Automated synchronization: automatic data upload from a linked data source. |
| **Cloud Environment** | An externally operated computing system that provides data and programs over the internet, rather than storing them locally. |
| **Confidential** | Marks data that may only be processed by Telekom-hosted models and must not be sent to external providers. Set per collection or per Space; a chat that uses such data becomes a confidential chat. See [Confidentiality](https://docs.smartchat.ai.t-systems.net/user/concepts/confidentiality/). |
| **Advanced Parameters** | Additional settings for fine-tuning a function or model. |
| **Ingestion Configuration** | The process of integrating data from a data source. Various configurations can be set for ingestion (speed vs. accuracy). |
| **LLM** | Large Language Model: an AI model for processing and generating text. |
| **Multimodal Model** | An AI model that can process different data types (e.g. text and images). |
| **Prompt** | User input (question or instruction to an AI). |
| **Privacy mode** | Earlier name of confidentiality in the release notes (“Lightweight Privacy Mode”). See [Confidentiality](https://docs.smartchat.ai.t-systems.net/user/concepts/confidentiality/). |
| **PSA DSK3-compliant** | Approved in the Privacy & Security Assessment (PSA) for data protection class 3 (DSK3). |
| **RAG** | Retrieval Augmented Generation: context-based document search with language model support. |
| **Space** | Smartchat’s tenant boundary. Every resource (files, collections, assistants, chats, …) belongs to exactly one Space and is isolated from all other Spaces. See [Spaces](https://docs.smartchat.ai.t-systems.net/user/concepts/spaces/). |
| **Assistants** | Configurations built on top of an existing AI model, combining a system prompt and knowledge, tailored to specific tasks and shared with others in the Space. |
| **Custom Prompt Templates** | Templates for standardizing repetitive queries. |
| **Custom Knowledge** | Can be used as context in individual chats and with assistants. |
| **Single Sign-On (SSO)** | A procedure where the user logs in once and can then access multiple applications without re-authenticating. |
| **System Prompt** | A predefined technical background instruction that is always included by a model. |
| **Tag** | A short keyword marker for categorizing chat histories. |
