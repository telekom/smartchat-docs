# Managing & Organizing Chats

Source: https://docs.smartchat.ai.t-systems.net/user/guide/managing-chats/

> Search chat histories, create folders, pin, archive, and import chats.

## [Searching chat histories](https://docs.smartchat.ai.t-systems.net/user/guide/managing-chats/#searching-chat-histories)

*\[Image: Search bar in the chat overview]*

Use the **search bar** on the left side to search content from past chats and find old entries.

## [Organizing chats in folders](https://docs.smartchat.ai.t-systems.net/user/guide/managing-chats/#organizing-chats-in-folders)

*\[Image: New folder button]*

*\[Image: Folder context menu]*

Use the **plus button** in the chat overview to create folders for organizing and grouping chats. The three-dot menu lets you rename folders. Existing chats can be moved into folders via drag & drop.

## [Pinning, renaming, and managing chats](https://docs.smartchat.ai.t-systems.net/user/guide/managing-chats/#pinning-renaming-and-managing-chats)

*\[Image: Chat context menu]*

Click the **three-dot icon** next to a chat to access the following actions:

- **Pin** — Pin the chat to the top of the list.
- **Rename** — Change the chat title.
- **Clone** — Create a copy of an existing chat.
- **Archive** — Remove from the overview without deleting. Can be [unarchived](https://docs.smartchat.ai.t-systems.net/user/guide/managing-chats/#unarchiving-chats) later.
- **Share** — Create a shareable link. Recipients can view and clone the chat, but not collaboratively edit it.
- **Move to folder**
- **Download** — Download the chat in various formats.
- **Delete** — Permanently remove the chat from the history (not recoverable).

> **Note**
>
> **Share** and **Clone** are not offered for [confidential chats](https://docs.smartchat.ai.t-systems.net/user/concepts/confidentiality/), so their content stays within Smartchat.

Use the **tag icon** next to the three-dot menu to add **tags** (keywords) to chats for more efficient grouping across folders. You can also search for tags in the chat search bar.

## [Unarchiving chats](https://docs.smartchat.ai.t-systems.net/user/guide/managing-chats/#unarchiving-chats)

Archived chats are no longer displayed in the chat overview. They can be restored via the **profile icon**.

*\[Image: Profile menu with "Archived Chats"]*

In this view, all archived chats can be restored individually (or all at once) or deleted. Archived chats can also be exported as a JSON file.

*\[Image: Archived chats dialog]*

## [Importing chats](https://docs.smartchat.ai.t-systems.net/user/guide/managing-chats/#importing-chats)

Go to **Settings** under the profile icon and navigate to the “Chats” section.

*\[Image: Settings in the profile menu]*

Here you can import chats in JSON format.

*\[Image: Chat import in settings]*
