# Customizing Smartchat

Source: https://docs.smartchat.ai.t-systems.net/user/guide/settings/

> Profile settings, chat dialog, and audio settings.

Open your personal settings for Smartchat and the interface via the **profile icon** in the top right.

*\[Image: General settings]*

## [General profile settings](https://docs.smartchat.ai.t-systems.net/user/guide/settings/#general-profile-settings)

*\[Image: Interface and conversation settings]*

The general settings allow you to configure the user interface:

- **Theme** — Light/dark mode
- **Language**
- **Notifications** — enable/disable
- **Popup delay** — how long popup windows remain visible
- **General system prompt** — always active (e.g. “Always respond in bullet points.”)
- **Advanced parameters** — should only be adjusted when specifically needed

> **Changed in v3.19.0**
>
> In a chat with an assistant that has its own system prompt, your general system prompt is no longer used. Put instructions that must apply there into the assistant’s system prompt.

## [Customizing the chat dialog](https://docs.smartchat.ai.t-systems.net/user/guide/settings/#customizing-the-chat-dialog)

*\[Image: Chat dialog settings]*

The interface settings let you configure the default parameters for the chat dialog. Options are grouped into **Interface**, **Conversation**, **Voice**, and **File**.

For example, under *Interface > Text direction* you can set whether text direction is left-to-right, right-to-left, or automatic.

## [Audio & speech settings](https://docs.smartchat.ai.t-systems.net/user/guide/settings/#audio--speech-settings)

*\[Image: Audio settings]*

The audio settings let you configure audio input and output:

- **STT** (Speech-to-Text) — convert speech to text
- **TTS** (Text-to-Speech) — convert text to speech
