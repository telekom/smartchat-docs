# Using Multiple Models Side by Side

Source: https://docs.smartchat.ai.t-systems.net/user/guide/multi-model/

> Multi-model chat and combining responses.

In each chat, you can choose which of the available language models to use. In addition to a single model, you can interact with two or more models simultaneously in a multi-model chat to compare and combine their responses.

## [Selecting multiple models](https://docs.smartchat.ai.t-systems.net/user/guide/multi-model/#selecting-multiple-models)

*\[Image: Multi-model selection]*

Click the **plus button** next to the currently selected model to add an additional model. All inputs will now be answered by both models in parallel. This feature is useful for comparing different AI models, cross-checking responses, or gathering different ideas for a specific task.

## [Combining responses](https://docs.smartchat.ai.t-systems.net/user/guide/multi-model/#combining-responses)

When using multiple models, responses can be merged into a single combined answer using the **branch icon** on the right side.
