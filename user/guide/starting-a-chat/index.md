# Starting a Chat

Source: https://docs.smartchat.ai.t-systems.net/user/guide/starting-a-chat/

> Open a new chat, select a model, and make inputs.

## [Open a new chat](https://docs.smartchat.ai.t-systems.net/user/guide/starting-a-chat/#open-a-new-chat)

*\[Image: Chat window with "New Chat" button]*

Click **“New Chat”** in the left sidebar to start a new (empty) chat. In each chat, you can choose which of the available language models to use. In addition to a single model, you can also interact with two or more models simultaneously in a multi-model chat to compare their responses.

## [Select a model](https://docs.smartchat.ai.t-systems.net/user/guide/starting-a-chat/#select-a-model)

*\[Image: Model selection menu]*

Click the **dropdown menu** showing the currently selected model to switch models. Model names include visual indicators:

- **Logo** (before the name): If it shows the Telekom T, the model is hosted by Telekom. These models are the most secure (PSA DSK3-compliant for confidential data). Models without the T logo are externally hosted and cannot be used for confidential or internal documents. In a [confidential chat](https://docs.smartchat.ai.t-systems.net/user/concepts/confidentiality/), only models with the T logo are offered.
- **Country flag** (after the name): Indicates which country the model is hosted in.
- **Image icon** (after the flag): If the image is white, it is a multimodal model that can process images in addition to text.

Depending on your organization’s configuration, you may also have access to [assistants](https://docs.smartchat.ai.t-systems.net/user/guide/workspaces/#creating-and-using-assistants).

## [Making inputs](https://docs.smartchat.ai.t-systems.net/user/guide/starting-a-chat/#making-inputs)

### [Writing manual prompts](https://docs.smartchat.ai.t-systems.net/user/guide/starting-a-chat/#writing-manual-prompts)

*\[Image: Prompt input in the chat window]*

A manual prompt is a directly written input in the chat interface. Type your query or instruction in the dialog window and send it using the arrow button or the Enter key.

### [Editing a prompt](https://docs.smartchat.ai.t-systems.net/user/guide/starting-a-chat/#editing-a-prompt)

*\[Image: Edit icon below the prompt]*

A prompt can be edited using the **pencil icon**. The response will be regenerated for the updated prompt. After editing, click “Send” to regenerate.

### [Speech to text](https://docs.smartchat.ai.t-systems.net/user/guide/starting-a-chat/#speech-to-text)

Instead of typing a prompt, you can dictate it: Smartchat converts the recording to text.

1. Click the **microphone** in the message box (**Record voice**) and start speaking.

   *\[Image: The microphone in the message box, with its tooltip Record voice]*

2. The first time, your browser asks whether Smartchat may use the microphone: allow it. If you blocked it before, allow it again in the browser’s site settings, which open from the icon next to the address bar.

   *\[Image: The browser’s site settings with the microphone permission set to Block]*

3. While you record, a timer shows the elapsed time against the maximum. Stop the recording to have it converted to text in the message box.

> **Recordings stop after about 10 minutes**
>
> A recording stops on its own at 9:50 and is transcribed as usual. For a longer dictation, record it in several parts.

### [Uploading files and screen captures](https://docs.smartchat.ai.t-systems.net/user/guide/starting-a-chat/#uploading-files-and-screen-captures)

Uploading files allows you to interact directly with your own documents. This creates a private chat session between you, Smartchat, and the uploaded documents. Uploaded documents are not stored outside the chat.

> **Confidential documents**
>
> An uploaded file has no confidentiality flag of its own. To keep a document on Telekom-hosted models, add it to a [confidential collection](https://docs.smartchat.ai.t-systems.net/user/guide/confidential-data/) and attach the collection instead.

Use the **plus icon** in the chat window to upload files from your file manager or take screenshots of open applications. Files can also be dragged and dropped into a chat.
