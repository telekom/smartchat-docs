# Working with Confidential Data

Source: https://docs.smartchat.ai.t-systems.net/user/guide/confidential-data/

> Step by step — create a confidential collection, chat with it, and see how Smartchat keeps confidential data on Telekom-hosted models.

Smartchat can keep confidential documents within Telekom-hosted infrastructure for you. This page walks through a typical example: a controlling team keeps the budget plan for 2027 in a confidential collection and asks questions about it. For the rules behind it, see [Confidentiality](https://docs.smartchat.ai.t-systems.net/user/concepts/confidentiality/).

## [1. Create a confidential collection](https://docs.smartchat.ai.t-systems.net/user/guide/confidential-data/#1-create-a-confidential-collection)

1. Open **Workspace → Collection** and click **Create Collection**.
2. Enter a name and a description.
3. Switch on **Confidential**. Hover over the label to see what it means.
4. Click **Create Collection**, then add your documents with the **+** button in the collection.

*\[Image: Create Collection form with the Confidential switch turned on]*

The collection now carries a shield in the collection list.

*\[Image: Collection list with the shield next to the confidential collection]*

To make an existing collection confidential, open it and switch on **Confidential** in its header. The change is saved right away.

*\[Image: Collection header with the Confidential switch]*

> **Tip**
>
> Put confidential documents into a confidential collection rather than uploading them straight into a chat. A file uploaded into a chat has no confidentiality flag of its own.

## [2. Use the collection in a chat](https://docs.smartchat.ai.t-systems.net/user/guide/confidential-data/#2-use-the-collection-in-a-chat)

In a new chat, type **#** and pick the collection. Confidential collections show the shield in the list.

*\[Image: Collection picker opened with # showing the confidential collection]*

As soon as the collection is attached, the chat is confidential. If an externally hosted model was selected, Smartchat switches to a Telekom-hosted model and tells you so.

*\[Image: Notification that the chat switched to a Telekom-hosted model]*

The shield icon next to the microphone shows that you are in a confidential chat.

*\[Image: Tooltip of the confidential chat icon in the chat input]*

## [3. What you can use in the chat](https://docs.smartchat.ai.t-systems.net/user/guide/confidential-data/#3-what-you-can-use-in-the-chat)

The model picker only offers models hosted by T-Systems. Externally hosted models are hidden.

*\[Image: Model picker showing only Telekom-hosted models and the confidential data note]*

Web search is greyed out in the **+** menu, because it would send parts of the conversation to an external search provider. Tools are not offered either.

*\[Image: Disabled web search entry in the + menu of a confidential chat]*

Ask your question as usual. The answer is generated by a Telekom-hosted model and cites the documents from your collection.

*\[Image: Answer from a Telekom-hosted model citing a document from the confidential collection]*

## [4. The chat stays confidential](https://docs.smartchat.ai.t-systems.net/user/guide/confidential-data/#4-the-chat-stays-confidential)

A confidential chat keeps its restrictions for its whole life:

- Removing the collection from the chat, or switching off **Confidential** on the collection later, does not lift them.
- **Share**, **Clone** and **Copy** are not offered in the chat menu, so the content stays within Smartchat. Export is still available.

If you need web search or an externally hosted model for a follow-up question, start a new chat without the confidential data.

## [Working in a confidential Space](https://docs.smartchat.ai.t-systems.net/user/guide/confidential-data/#working-in-a-confidential-space)

If your Space Owner has marked the whole Space as confidential, every chat in it is confidential from the start, with all the restrictions above. You do not have to mark individual collections.

When you open a confidential Space from a chat, Smartchat asks you to confirm first. **Continue** opens the Space and restricts the current chat to Telekom-hosted models for good; **Cancel** keeps you where you are.

*\[Image: Confirmation dialog: You selected a Confidential Space]*

## [Assistants with confidential collections](https://docs.smartchat.ai.t-systems.net/user/guide/confidential-data/#assistants-with-confidential-collections)

An [assistant](https://docs.smartchat.ai.t-systems.net/user/guide/workspaces/#creating-and-using-assistants) that uses a confidential collection must run on a Telekom-hosted base model:

- When you attach a confidential collection in the assistant editor, the base model list only offers Telekom-hosted models. A previously chosen externally hosted base model is removed, and the editor tells you why.
- An existing assistant whose collection becomes confidential while it runs on an externally hosted model is shown as **Unavailable** in the model picker until you edit it and pick a Telekom-hosted base model.

Chats with such an assistant are confidential, just as if you had attached the collection yourself.
