# Roles, Permissions & Access Control

Source: https://docs.smartchat.ai.t-systems.net/user/concepts/roles-permissions-access-control/

> How roles, permissions and access control differ, and how groups connect them.

Roles, permissions and access control each decide something different. Each concept has its own page:

| Concept | Decides | Applies to |
| - | - | - |
| **[Roles](https://docs.smartchat.ai.t-systems.net/user/concepts/roles/)** | Who administers Smartchat and its Spaces: members, groups and settings | The whole instance or one Space |
| **[Permissions](https://docs.smartchat.ai.t-systems.net/user/concepts/permissions/)** | Which features Space Users can use and which actions they can take, such as using web search or building agents | One Space |
| **[Access control](https://docs.smartchat.ai.t-systems.net/user/concepts/access-control/)** | Who can use or edit an item, such as a collection or an agent | A single item |

What a role allows cannot be changed per person. Permissions only concern Space Users, because Space Owners have every permission of their Space through their role.

[Groups](https://docs.smartchat.ai.t-systems.net/user/concepts/groups/) connect permissions and access control: permissions are set on groups, and items are shared with groups.
