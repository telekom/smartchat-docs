# Denkaufwand

Source: https://docs.smartchat.ai.t-systems.net/de/user/guide/reasoning-effort/

> Legen Sie fest, wie viel ein Reasoning-Modell nachdenkt, bevor es antwortet.

Manche Modelle denken eine Frage durch, bevor sie antworten. Der **Denkaufwand** legt fest, wie viel sie dabei nachdenken dürfen: Mehr Aufwand liefert bei schwierigen Fragen wie Analysen, Berechnungen oder Code meist bessere Antworten, die Antwort dauert aber länger und verbraucht mehr Tokens.

## [Den Aufwand wählen](https://docs.smartchat.ai.t-systems.net/de/user/guide/reasoning-effort/#den-aufwand-w%C3%A4hlen)

Die Auswahl zeigt den gewählten Aufwand, hier Standard.

1. Wählen Sie ein Modell, das den Denkaufwand unterstützt. Im Eingabefeld erscheint dann eine Auswahl, die den aktuellen Aufwand zeigt, zum Beispiel **Standard**. Sie erscheint nur, wenn alle gewählten Modelle den Denkaufwand unterstützen, und verschwindet wieder, wenn Sie ein Modell hinzunehmen, das das nicht tut.
2. Öffnen Sie sie und wählen Sie **Niedrig**, **Mittel** oder **Hoch**.
3. Senden Sie Ihre Nachricht. Der Aufwand gilt für die Nachrichten, die Sie senden, bis Sie ihn ändern.

Je nach Modell bietet die Liste außerdem eine erste Option, die den Aufwand dem Modell überlässt: **Standard**, **Automatisch** oder **Deaktiviert** bei Modellen, die dann ohne vorheriges Nachdenken antworten.

> **Wann Sie ihn erhöhen**
>
> Beginnen Sie mit dem Standard des Modells. Erhöhen Sie den Aufwand, wenn eine Antwort auf eine anspruchsvolle Frage Schritte auslässt oder Details falsch hat, und senken Sie ihn bei kurzen Fragen, bei denen Geschwindigkeit wichtiger ist.

Der Denkaufwand gilt nicht für [Deep Dive](https://docs.smartchat.ai.t-systems.net/de/user/guide/deep-dive/), das selbst entscheidet, wie lange es recherchiert.
