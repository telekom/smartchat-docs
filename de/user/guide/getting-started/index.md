# Erste Schritte

Source: https://docs.smartchat.ai.t-systems.net/de/user/guide/getting-started/

> Registrierung und Anmeldung beim Smartchat.

## [Registrierung & Anmeldung](https://docs.smartchat.ai.t-systems.net/de/user/guide/getting-started/#registrierung--anmeldung)

Wenn verfügbar, melden Sie sich bitte mit dem **Single-Sign-On (SSO)** Ihres Unternehmens an. Der Smartchat unterstützt OIDC-kompatible SSO-Provider.

Falls SSO auf Ihrere Instanz nicht verfügbar sein sollte, befolgen Sie die untenstehenden Anweisungen.

### [Registrierung](https://docs.smartchat.ai.t-systems.net/de/user/guide/getting-started/#registrierung)

Ihr Konto wird erstellt, wenn ein Anwendungsinhaber oder der Space Owner Ihres Spaces Sie [als Mitglied hinzufügt](https://docs.smartchat.ai.t-systems.net/de/user/admin/managing-space-members/). Sie erhalten eine E-Mail mit einem Verifizierungslink. Bitte überprüfen Sie Ihre E-Mail und verwenden Sie die Option “Passwort vergessen”, um ein neues Passwort zu erstellen. Ihr **neues Passwort** muss **mindestens 16 Zeichen** enthalten.

### [Anmelden](https://docs.smartchat.ai.t-systems.net/de/user/guide/getting-started/#anmelden)

Melden Sie sich mit Ihrer E-Mail-Adresse und Ihrem Passwort an oder nutzen Sie Ihr Firmen-SSO.

*\[Image: Anmeldeseite]*

Je nach Installation werden Sie zusätzlich nach einem Code aus einer Authenticator-App gefragt. Siehe [Zwei-Faktor-Authentifizierung](https://docs.smartchat.ai.t-systems.net/de/user/concepts/two-factor-authentication/).
