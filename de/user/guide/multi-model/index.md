# Verschiedene KI-Modelle nebeneinander nutzen

Source: https://docs.smartchat.ai.t-systems.net/de/user/guide/multi-model/

> Multi-Modell-Chat und Antworten kombinieren.

In jedem Chat kann ausgewählt werden, welches der verfügbaren KI-Modelle verwendet werden soll. Neben einem ausgewählten Modell kann auch mit zwei oder mehr Modellen gleichzeitig in einem Multi-Modell-Chat interagiert werden, sodass die Antworten auf Eingabeprompts miteinander verglichen und kombiniert werden können.

## [Mehrere Modelle auswählen](https://docs.smartchat.ai.t-systems.net/de/user/guide/multi-model/#mehrere-modelle-ausw%C3%A4hlen)

*\[Image: Multi-Modell-Auswahl]*

Durch Klicken auf den **Plus-Button** neben dem derzeit ausgewählten Modell kann ein zusätzliches Modell zum Chatten hinzugefügt werden. Alle Eingaben werden nun von beiden ausgewählten Modellen parallel beantwortet. Diese Funktion kann nützlich sein, wenn verschiedene KI-Modelle verglichen, Antworten abgeglichen oder verschiedene Ideen für eine bestimmte Aufgabe gesammelt werden sollen.

## [Antworten kombinieren](https://docs.smartchat.ai.t-systems.net/de/user/guide/multi-model/#antworten-kombinieren)

Bei der Nutzung mehrerer Modelle können die Antworten mittels des **Ast-Symbols** auf der rechten Seite zu einer zusammengeführten Antwort kombiniert werden.
