# Glossar

Source: https://docs.smartchat.ai.t-systems.net/de/user/glossary/

> Glossar der wichtigsten Begriffe im Smartchat.

| Begriff | Bedeutung |
| - | - |
| **Anwendungsinhaber** | Globale Verantwortung für die gesamte Smartchat-Anwendung; kann alle Spaces und Nutzer verwalten. |
| **API-Key** | Ein eindeutiger Zugangsschlüssel, mit dem externe Systeme sicher auf die Funktionen des Smartchat zugreifen können. |
| **Arbeitsbereich** | Bereich, um selbstdefinierte Ressourcen (Assistenten, Kollektionen, Prompt-Vorlagen) zu erstellen, zu bearbeiten oder zu löschen. |
| **Arbeitsbereich-Ressourcen** | Umfasst drei Kategorien: Assistenten, selbstdefiniertes Wissen und selbstdefinierte Prompt-Vorlagen, jeweils individuell erstellt/angepasst. |
| **Auto-Sync** | Automatisierte Synchronisation: der automatisierte Datenupload aus einer verknüpften Datenquelle. |
| **Cloud-Umgebung** | Ein extern betriebenes Rechensystem, das Daten und Programme über eine Internetverbindung bereitstellt, anstatt sie lokal zu speichern. |
| **Erweiterte Parameter** | Zusätzliche Einstellungen zur Feinsteuerung einer Funktion oder eines Modells. |
| **Ingestion-Konfiguration** | Das Einbinden von Daten aus einer Datenquelle. Für die Ingestion können verschiedene Konfigurationen vorgenommen werden (Geschwindigkeit vs. Genauigkeit). |
| **LLM** | Large Language Model (Sprachmodell): KI-Modell zur Verarbeitung und Generierung von Text. |
| **Multimodales Modell** | Ein KI-Modell, das verschiedene Datentypen (z.B. Text und Bild) verarbeiten kann. |
| **Prompt** | Eingabe durch den Nutzenden (Frage bzw. Aufforderung an eine KI). |
| **Privacy Mode** | Früherer Name der Vertraulichkeit in den Release Notes („Lightweight Privacy Mode“). Siehe [Vertraulichkeit](https://docs.smartchat.ai.t-systems.net/de/user/concepts/confidentiality/). |
| **PSA DSK3-konform** | Im Privacy & Security Assessment (PSA) für Datenschutzklasse 3 (DSK3) freigegeben. |
| **RAG** | Retrieval Augmented Generation (Abfragegestützte Generierung): Kontextbasierte Dokumentensuche mit Sprachmodell-Unterstützung. |
| **Space** | Die Mandantengrenze von Smartchat. Jede Ressource (Dateien, Kollektionen, Assistenten, Chats …) gehört zu genau einem Space und ist von allen anderen Spaces isoliert. Siehe [Spaces](https://docs.smartchat.ai.t-systems.net/de/user/concepts/spaces/). |
| **Assistenten** | Konfigurationen auf Basis eines bestehenden KI-Modells, die durch Systemprompt und Wissen für bestimmte Aufgaben angepasst und mit anderen im Space geteilt werden können. |
| **Selbstdefinierte Prompt-Vorlagen** | Vorlagen, mit denen sich wiederholende Anfragen standardisiert werden können. |
| **Selbstdefiniertes Wissen** | Kann in einzelnen Chats und bei Assistenten als Kontext genutzt werden. |
| **Single-Sign-On (SSO)** | Einmalanmeldung: ein Verfahren, bei dem sich der Nutzer einmal anmeldet und danach auf mehrere Anwendungen zugreifen kann. |
| **Systemprompt** | Vordefinierte, technische Hintergrundanweisung, die von einem Modell stets einbezogen wird. |
| **Tag** | Kurzer Stichwort-Marker, mit dem Chatverläufe kategorisiert werden können. |
| **Vertraulich** | Kennzeichnet Daten, die nur von Telekom-gehosteten Modellen verarbeitet und nicht an externe Anbieter gesendet werden dürfen. Wird pro Kollektion oder pro Space gesetzt; ein Chat, der solche Daten verwendet, wird zu einem vertraulichen Chat. Siehe [Vertraulichkeit](https://docs.smartchat.ai.t-systems.net/de/user/concepts/confidentiality/). |
