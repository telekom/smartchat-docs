# Rollen, Berechtigungen & Zugriffskontrolle

Source: https://docs.smartchat.ai.t-systems.net/de/user/concepts/roles-permissions-access-control/

> Wie sich Rollen, Berechtigungen und Zugriffskontrolle unterscheiden und wie Gruppen sie verbinden.

Rollen, Berechtigungen und Zugriffskontrolle regeln Verschiedenes. Jedes Konzept hat seine eigene Seite:

| Konzept | Regelt | Gilt für |
| - | - | - |
| **[Rollen](https://docs.smartchat.ai.t-systems.net/de/user/concepts/roles/)** | Wer Smartchat und seine Spaces verwaltet: Mitglieder, Gruppen und Einstellungen | Die ganze Instanz oder einen Space |
| **[Berechtigungen](https://docs.smartchat.ai.t-systems.net/de/user/concepts/permissions/)** | Welche Funktionen Space User nutzen und welche Aktionen sie ausführen können, etwa die Websuche nutzen oder Agenten bauen | Einen Space |
| **[Zugriffskontrolle](https://docs.smartchat.ai.t-systems.net/de/user/concepts/access-control/)** | Wer ein Element verwenden oder bearbeiten kann, etwa eine Kollektion oder einen Agenten | Ein einzelnes Element |

Was eine Rolle erlaubt, lässt sich nicht pro Person ändern. Berechtigungen betreffen nur Space User, denn Space Owner haben durch ihre Rolle jede Berechtigung ihres Space.

[Gruppen](https://docs.smartchat.ai.t-systems.net/de/user/concepts/groups/) verbinden Berechtigungen und Zugriffskontrolle: Berechtigungen werden an Gruppen gesetzt, und Elemente werden mit Gruppen geteilt.
