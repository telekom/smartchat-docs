Space-Administration

Das Space Administration Panel ist die separate Benutzeroberfläche, in der Administratoren Smartchat konfigurieren, sowohl auf Anwendungsebene als auch innerhalb einzelner Spaces. Reguläre Benutzer können es nicht sehen.

Wer hat Zugriff

Abschnitt betitelt „Wer hat Zugriff“

Drei administrative Rollen sehen verschiedene Teile dieses Panels:

  • Application Owner
  • Space Owner
  • Data Scientist

Ein Benutzer kann eine beliebige Kombination dieser Rollen haben, einschließlich verschiedener Space-Owner-Zuweisungen pro Space. Was jede Rolle kann, erfahren Sie unter Rollen und Rollen & Berechtigungen.
